# TVMazeKit

TypeScript SDK and MCP server for the TVMaze API.

## Packages

| Package | Description |
|---------|-------------|
| [@tvmazekit/sdk](./packages/sdk) | TypeScript SDK for the TVMaze API |
| [@tvmazekit/mcp](./packages/mcp) | MCP server for TVMaze API integration |

## Installation

```bash
# SDK
pnpm add @tvmazekit/sdk

# MCP Server
pnpm add @tvmazekit/mcp
```

## Development

```bash
# Install dependencies
pnpm install

# Build all packages
pnpm build

# Run tests
pnpm test

# Lint
pnpm lint

# Type check
pnpm typecheck
```
